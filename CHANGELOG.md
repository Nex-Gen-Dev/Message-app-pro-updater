# Changelog

## [1.0.0] - 2026-11-09

### Added
- Unified thread list combining SMS, WhatsApp, and Google Voice
- WhatsApp integration via QR code linking (Baileys bridge)
- Google Voice integration via Google OAuth (Puppeteer bridge)
- Source badges (WhatsApp green, Google Voice teal, SMS blue) on thread list
- Filter chips: All / SMS / WhatsApp / Google Voice
- Push notifications for bridge messages
- In-app auto-updater with background checks
- Onboarding tour for first-time users
- Modern Material Design UI with customizable themes
- Full SMS/MMS support (QKSMS base)
