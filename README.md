# Message App Pro - Updates

This repository hosts releases for **Message App Pro**, a unified SMS + WhatsApp + Google Voice messaging app for Android.

## How Updates Work

The app automatically checks this repository for new releases every 4 hours. When a new version is available, you'll receive a notification and can update directly from within the app.

### Manual Update Check
Go to **Settings → Check for Updates** to manually check for the latest version.

### Download Latest
Visit the [Releases](https://github.com/nex-gen-dev/message-app-pro-updater/releases) page to download the latest APK.

## Installation

1. Download the latest `.apk` file from [Releases](https://github.com/nex-gen-dev/message-app-pro-updater/releases/latest)
2. On your Android device, enable "Install from Unknown Sources" if prompted
3. Open the downloaded APK to install
4. Future updates will be delivered automatically through the app

## Version History

See the [Releases](https://github.com/nex-gen-dev/message-app-pro-updater/releases) page for full changelog.

## About

Message App Pro is a unified messaging app that combines SMS, WhatsApp, and Google Voice into a single, beautiful interface. Built on the open-source QKSMS messenger.

**Note:** Source code is maintained in a private repository. This repo is solely for distributing releases.
